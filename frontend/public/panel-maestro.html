🔒 Sistema de licencias JWT

Formato
JWT firmado con LICENSE_SECRET. Payload: install_id, plan, expires_at, hwid, plan_type.
Verificación
App hace ping cada 15 días. Sin internet: 30 días grace period.
HWID binding
1ª activación guarda SHA-256(hostname+platform+arch+RAM+MAC) → si cambia, bloquea.
Transferencia
Admin puede transferir a otro install_id conservando Stripe subscription intacto.
Master key
MB-MASTER-BRUGULAT-2026-OWNER funciona en cualquier PC del mundo (para ti).

🚀 Publicar una nueva versión

Solo 1 comando. La versión sube sola (2.0.36 → 2.0.37 → 2.0.38...), compila el .exe, sube el instalador a GitHub Releases y los clientes lo reciben en cuanto abren el programa. 
cd C:\medicarplus\electron
npm run release
⚠️ Antes de npm run release: tanca la app MediCar Plus del PC (si está abierta bloquea la compilación).

🔁 Actualizar la app en tu propio PC

  1. Descarga el ZIP nuevo: medicarplus.es/downloads/medicar-plus-electron.zip
  2. Cierra MediCar Plus.
  3. PowerShell: 
    cd C:\medicarplus
Remove-Item -Recurse -Force electron
Expand-Archive "$HOME\Downloads\medicar-plus-electron.zip" -DestinationPath C:\medicarplus -Force
cd C:\medicarplus\electron
npm install

🆘 Troubleshooting rápido

Cliente ve "Licencia bloqueada"
Ha cambiado de PC. Admin → busca su install_id → botón 🔓 Desbloquear HWID.
Cliente cambia de ordenador
Admin → busca licencia → botón 🔄 Transferir → pega el nuevo install_id. Stripe sigue intacto.
Cliente cambia de email
Admin → detalle licencia → 📧 Cambiar email. Actualiza en Mongo + Stripe Customer.
404 en SMS/Cites (raro)
El backend detecta y publica su URL sola en GitHub (api-endpoint.json). Si sigue → dile al cliente Configuración → 🔄 Comprobar última versión.
Google muestra info antigua
Normal. Google tarda 3-7d en actualizar tras enviar sitemap. Volver a "Solicitar indexación" NO acelera.
Popup bloqueado en Electron
Los botones "Panel Admin", "Panel Maestro" abren en navegador vía shell.openExternal. Si no abre: revisar preload.js.
