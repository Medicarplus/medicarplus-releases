💳 Configurar Stripe Subscriptions

Guia pas a pas per activar els pagaments recurrents automàtics a MediCar Plus. Segueix-la quan tinguis empresa constituïda i compte bancari a nom de l'empresa.

⚠️ ABANS DE COMENÇAR
Per rebre pagaments recurrents cal empresa constituïda (autònom o SL) amb activitat econòmica declarada a Hisenda, i compte bancari a nom de l'empresa (no personal). Sense això, cobrar seria frau fiscal.

🎯 Objectiu

Els clients paguen automàticament cada mes/any amb targeta, i la seva llicència JWT es renova sola via webhooks quan Stripe confirma el cobrament. Si algú cancel·la (o falla el cobrament), la llicència queda inactiva automàticament.

📋 Passos

1️⃣ Crear compte a Stripe
  • Ves a dashboard.stripe.com/register
  • Registra't amb l'email de l'empresa
  • Mode Test queda activat per defecte — ideal per proves sense diners reals
  • Per activar Mode Live cal introduir el NIF/CIF de l'empresa, IBAN i verificar identitat
2️⃣ Crear els 4 productes/preus

Al Dashboard → Products → Add product. Crea un producte "MediCar Plus" i afegeix aquests 4 preus recurrents:

Nom del preuImportFacturacióDivisa
STD Mensual29,90 €Cada 1 mesEUR
STD Anual299,90 €Cada 1 anyEUR
PREMIUM Mensual39,90 €Cada 1 mesEUR
PREMIUM Anual399,90 €Cada 1 anyEUR

Quan crees cada preu, Stripe genera un Price ID tipus price_1AbCdEf.... Copia'ls tots quatre.

3️⃣ Copiar les claus API

Dashboard → Developers → API keys. Copia la Secret key:

  • Mode Test: comença per sk_test_...
  • Mode Live: comença per sk_live_...
NO COMPARTEIXIS mai la Secret Key en públic (repos git, chats, screenshots). Si es filtra, revoca-la immediatament des del mateix Dashboard.
4️⃣ Configurar el Webhook

Dashboard → Developers → Webhooks → Add endpoint:

  • Endpoint URL: https://api.medicarplus.com/api/webhook/stripe (substitueix pel domini real del teu backend)
  • Events to send: selecciona aquests 5:
    • checkout.session.completed
    • invoice.paid
    • invoice.payment_failed
    • customer.subscription.updated
    • customer.subscription.deleted

Un cop creat, clica al webhook i copia el Signing secret (comença per whsec_...).

5️⃣ Configurar les variables al servidor

Edita /app/backend/.env i afegeix (o passa'ls al teu proveïdor de hosting):

STRIPE_API_KEY=sk_test_51AbCdEf...       # o sk_live_ a producció
STRIPE_WEBHOOK_SECRET=whsec_ABC123...
STRIPE_PRICE_STD_MES=price_1AbCdEf...
STRIPE_PRICE_STD_ANY=price_1GhIjKl...
STRIPE_PRICE_PREMIUM_MES=price_1MnOpQr...
STRIPE_PRICE_PREMIUM_ANY=price_1StUvWx...

Reinicia el backend perquè carregui les variables noves:

sudo supervisorctl restart backend
6️⃣ Verificar que està tot bé

Fes una petició GET a:

curl https://api.medicarplus.com/api/payments/subscription/enabled

Ha de retornar:

{
  "enabled": true,
  "stripe_api_key_present": true,
  "packages": {
    "STD_MES": true,
    "STD_ANY": true,
    "PREMIUM_MES": true,
    "PREMIUM_ANY": true
  }
}

Si algun paquet apareix com false, revisa el .env.

🧪 Provar amb targeta de test

En Mode Test, Stripe accepta targetes falses:

  • Èxit: 4242 4242 4242 4242 · Data futura · CVC qualsevol
  • Requereix autenticació 3DS: 4000 0025 0000 3155
  • Cobrament rebutjat: 4000 0000 0000 9995

Més targetes: stripe.com/docs/testing

🔄 Com funciona la renovació automàtica

  1. Client paga la primera vegada → Stripe crea Customer + Subscription
  2. Webhook checkout.session.completed → backend genera JWT amb expires_at = ara + 30 dies (o 365)
  3. Cada mes/any, Stripe cobra automàticament → webhook invoice.paid → backend estén expires_at +30/+365 dies
  4. Si el client cancel·la o falla el cobrament → webhook customer.subscription.deleted → llicència marcada com cancelled
✅ Portal del client (self-service) · JA ACTIU · v2.1.10
Stripe ofereix un portal on el client pot cancel·lar, canviar targeta i veure factures. Ja està implementat al backend com a POST /api/payments/billing-portal i integrat a l'app (⚙️ Configuración → 🧾 Gestionar subscripció) i a la web pública (peu de pàgina → "Gestionar mi suscripción").

⚠️ CAL configurar-lo un cop a Stripe Dashboard perquè funcioni:
  1. Anar a Stripe Dashboard → Settings → Billing → Customer Portal (dashboard.stripe.com/test/settings/billing/portal en TEST, dashboard.stripe.com/settings/billing/portal en LIVE)
  2. Activar les seccions:
    • Customer information — permet al client actualitzar email/adreça de facturació
    • Invoice history — permet descarregar factures PDF (obligatori per DGT/Hisenda)
    • Payment methods — canviar targeta
    • Cancel subscriptions — activar immediately o at end of billing period (recomanat: end of period, així el client segueix usant l'app fins que acabi el mes pagat)
    • Update subscriptions (opcional) — permet al client canviar de STD a PREMIUM sense passar per tu
  3. A Business information: afegir nom del negoci "MediCar Plus", email de suport info@medicarplus.es, i URL de la teva Privacy Policy i Terms of Service (obligatori per LIVE mode).
  4. Desar canvis. La URL del portal es genera dinàmicament amb cada crida a l'endpoint (session token amb TTL curt).
⚠️ Sense aquest pas, la crida a /api/payments/billing-portal tornarà error 502 de Stripe.

🧾 Flux complet de cancel·lació

  1. Client obre app (o web) → clica "Gestionar subscripció"
  2. Backend cerca stripe_customer_id a la col·lecció subscriptions per install_id o customer_email
  3. Backend crida stripe.billing_portal.Session.create(customer=..., return_url=...)
  4. Backend retorna URL única de sessió (validesa curta, ~1h)
  5. Frontend obre la URL a nova pestanya del navegador
  6. Client cancel·la des del portal oficial de Stripe
  7. Stripe envia webhook customer.subscription.updated amb cancel_at_period_end=true
  8. Backend actualitza subscriptions.cancel_at_period_end=true, però la llicència segueix activa fins current_period_end
  9. Al final del període, Stripe envia customer.subscription.deleted → backend marca la llicència com canceled
  10. Al proper /api/licenses/verify, l'app veu que ha expirat i demana renovar

💰 Comissions de Stripe

Stripe cobra 1,4% + 0,25 € per targetes europees, i 2,9% + 0,25 € per no-europees. Amb el pla STD Anual (299,90€) pagaries uns 4,45 € de comissió (~1,48%).

La resta va directe al teu compte bancari (payout automàtic setmanal o diari, configurable).
