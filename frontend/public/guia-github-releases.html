🚀 Auto-updates amb GitHub Releases

Aquesta guia configura el sistema perquè, quan tu facis una nova versió, tots els clients rebin l'actualització automàticament sense reinstal·lar res.

✅ Ja tens tot preparat al codi:
· main.js conté electron-updater configurat
· package.json ja té la secció build.publish amb provider GitHub
· .github/workflows/release.yml està creat i llest per compilar a Windows

Només falta que creïs el repo, hi pugis el codi i configuris el token.

📋 Passos

1️⃣ Crear el repositori privat a GitHub
  • Ves a github.com/new
  • Repository name: medicar-plus-releases (o el nom que vulguis)
  • Visibility: Private ⚠️ (el codi és teu)
  • Clica Create repository
2️⃣ Actualitzar package.json amb el teu usuari

Edita /app/commercial/electron/package.json i canvia:

"publish": [
  {
    "provider": "github",
    "owner": "TEU_USUARI_GITHUB",     ← posa aquí el teu usuari real
    "repo": "medicar-plus-releases"    ← nom del repo que has creat
  }
]
3️⃣ Pujar el codi al repositori

Des de PowerShell (dins la carpeta del projecte Electron):

cd C:\ruta\a\medicar-plus\electron

git init
git add .
git commit -m "MediCar Plus v2.0.0 initial"
git branch -M main
git remote add origin https://github.com/TEU_USUARI/medicar-plus-releases.git
git push -u origin main
4️⃣ Crear un Personal Access Token

Necessari perquè GitHub Actions pugui publicar les Releases:

  • Ves a github.com/settings/tokens/new
  • Note: MediCar Plus - electron-builder
  • Expiration: No expiration (o 1 any i renoves)
  • Select scopes: marca només repo (tots els sub-checks)
  • Clica Generate token i copia el token (només es veu una vegada!)
5️⃣ Guardar el token com a secret al repo
  • Ves al teu repo → Settings → Secrets and variables → Actions
  • Clica New repository secret
  • Name: GH_TOKEN
  • Secret: enganxa el token que has copiat
  • Clica Add secret
6️⃣ Publicar una nova versió

Quan vulguis alliberar una nova versió:

# 1. Actualitza la versió a package.json
#    per exemple: "version": "2.0.1"

# 2. Commit + tag + push
git add package.json
git commit -m "Release v2.0.1"
git tag v2.0.1
git push origin main --tags

Automàticament:

  1. GitHub Actions detecta el tag v2.0.1
  2. Compila l'installer NSIS + versió portable a Windows
  3. Puja els .exe i el latest.yml a GitHub Releases
  4. Els clients existents, en obrir l'app, reben notificació automàtica
7️⃣ Verificar que ha funcionat
  • Ves al teu repo → pestanya Actions — has de veure el workflow verd (~5 min)
  • Ves a Releases — has de veure la v2.0.1 amb els .exe adjunts
  • Obre MediCar Plus en un ordinador amb versió antiga — al cap d'uns 5s apareixerà un diàleg "MediCar Plus v2.0.1 està llest per instal·lar"

🔄 Com funciona per dins

  1. App arrenca → electron-updater consulta github.com/TEU_USUARI/medicar-plus-releases/releases/latest
  2. Compara la versió instal·lada amb l'última publicada
  3. Si n'hi ha una nova → descarrega el .exe en background
  4. Un cop descarregat → mostra diàleg "Reiniciar i actualitzar ara / Més tard"
  5. Al reiniciar, s'instal·la la nova versió sobre l'antiga
⚠️ Repo privat vs públic
Si el repo és privat, electron-updater necessita un token dins l'app per llegir les releases. Això és més segur però requereix afegir GH_TOKEN al preload. Per començar, la solució més senzilla és fer el repo públic — el codi ja va obfuscat al .exe, així que ningú podrà llegir-lo, i les Releases són simplement els binaris compilats.

📌 Regles de versionat

  • Patch (bugs): 2.0.0 → 2.0.1
  • Minor (features): 2.0.1 → 2.1.0
  • Major (canvis grans/incompatibles): 2.1.0 → 3.0.0

El tag ha de coincidir amb la version del package.json (però amb la v davant): 2.0.1 a package.json → tag v2.0.1.
