3. Flux complet de venda · pas a pas

PAS 1 · El client entra al teu formulari
Envies el link /request-license per email o el poses al peu del teu mail.

Al formulari veu:
  • Les 3 targetes de preu (TRIAL gratis · STD 29,90€/mes o 299,90€/any · PREMIUM 39,90€/mes o 399,90€/any)
  • Toggle MENSUAL / ANUAL per triar periodicitat
  • Formulari amb dades del centre (Empresa, Contacte, Email, NIF, Telèfon)
  • Install ID opcional (si encara no té l'app, ho deixa buit)
  • Consent GDPR obligatori
PAS 2 · La sol·licitud arriba al teu admin
Entres a /admin amb la teva clau. Veuràs:
  • Comptador "Sol·licituds" amb badge blau si en tens de pendents
  • Llista amb empresa, email, telèfon, pla demanat, data
  • Botons per aprovar / rebutjar / veure detalls
  • Botó 📧 Enviar per email que genera un mailto: preformatat amb la clau i les instruccions
PAS 3 · Cobres al client
Tens 3 opcions (mira la secció 4):
  1. 🏦 Transferència bancària (l'única disponible avui)
  2. 💳 Stripe Checkout one-off (en mode test)
  3. 🔄 Stripe Subscriptions (codi llest, activa-ho quan tinguis empresa)
PAS 4 · Aprovar i generar la llicència
Al admin panel, clica "✅ Aprovar i generar llicència". Es genera un JWT únic (eyJhbGci...) vinculat al centre.

Envia'l per email al client amb:
  1. La clau JWT
  2. El link de descàrrega de l'.exe (WeTransfer/Drive per ara, GitHub Releases quan l'activis)
  3. La guia d'instal·lació
PAS 5 · El client instal·la i activa
  1. Instal·la l'exe
  2. A la pantalla d'activació, enganxa el JWT
  3. L'app verifica online contra el teu servidor
  4. Un cop activat, apareix el wizard per configurar noms d'empreses + socis
  5. Ja pot treballar
PAS 6 · Verificació periòdica (auto)
L'app fa un ping al teu servidor cada 15 dies. Si tu revoques la llicència (per exemple no ha pagat la renovació), la propera vegada que faci ping es bloqueja i torna a la pantalla d'activació.
Si el client no té internet, l'app segueix funcionant fins a 30 dies offline.

🔄 Stripe Subscriptions (Opció A — auto-renewal) CODI LLEST

Novetat 07/2026: El sistema ja té preparats 4 endpoints i el webhook per gestionar subscripcions:
  • POST /api/payments/create-subscription — crea checkout mode subscripció
  • GET /api/payments/subscription/enabled — feature-flag que retorna false fins configurar Price IDs
  • GET /api/payments/subscription/status/{id} — polling
  • GET /api/payments/subscription/list — llista admin
El webhook escolta invoice.paid, customer.subscription.deleted, etc. i renova/revoca el JWT automàticament sense que hagis de fer res.
Com funciona quan el client paga per subscripció:
  1. Client clica "Pagar amb targeta" (botó que apareixerà quan activis Subscriptions)
  2. Stripe fa 1a càrrega → webhook checkout.session.completed → genera JWT (30/365 dies)
  3. Cada mes/any Stripe cobra sol → webhook invoice.paid → estén JWT +30/+365 dies
  4. Si el client cancel·la o falla el cobrament → webhook customer.subscription.deleted → JWT revocat
⏸️ BLOQUEJAT PER TU: Cal constituir empresa (autònom o SL) i obrir Stripe account. Sense això no pots rebre pagaments recurrents legalment. Un cop fet, segueix la guia dedicada (5 minuts):
  1. Crear compte Stripe amb NIF empresa
  2. Crear 4 productes recurrents (STD Mes/Any, PREMIUM Mes/Any)
  3. Copiar els 4 Price IDs (price_1xxx...) al fitxer .env
  4. Configurar el webhook a https://el-teu-domini.com/api/webhook/stripe
  5. Reiniciar backend
Automàticament els Endpoints s'activen i el botó "Pagar amb targeta" apareix al formulari públic.

Comissions Stripe (referència)

  • Targetes europees: 1,4% + 0,25€ per transacció
  • Targetes no-europees: 2,9% + 0,25€
  • Per un pla STD Anual de 299,90€: uns 4,45€ de comissió (≈1,48%)

6. Mòdul SMS/WhatsApp

Què fa

Envia recordatoris massius (renovacions carnet, revisions caducades) via SMS/WhatsApp. Estalvia el cost de cartes físiques.

Com s'usa dins l'app

  1. Botó 📱 Avisos al header (verd, al costat d'IRPF)
  2. Es divideix en 5 seccions:
    • Importar CSV — puja el llistat DGT (Nom, Cognom1, Cognom2, Telèfon, DNI, Data caducitat, Adreça). Detecció automàtica de columnes
    • Afegir manual — Nom + Telèfon directament
    • Missatge amb variables — {NOM}, {DNI}, {DATA_CADUCITAT}, {ADRECA}
    • Canals — checkboxes SMS / WhatsApp / els dos
    • Contactes — checkboxes individuals + preview del missatge personalitzat
  3. Accions:
    • 📤 Exportar CSV — descarrega telèfon + missatge personalitzat (per LabsMobile/SMSarena)
    • 🚀 Enviar avisos — via Twilio (cal configuració)
    • 📜 Historial — últims 5000 enviaments amb filtre per data
⚠️ Falta a la CSV del DGT: el fitxer que reps del proveïdor DGT no inclou columna Telefono. Cal demanar al teu proveïdor que l'afegeixi — sense telèfon no es pot enviar SMS.

Estat Twilio

Endpoints /api/notifications/send i /api/notifications/history operatius, però retornen 503 fins que configuris:
  • TWILIO_ACCOUNT_SID (comença per AC...)
  • TWILIO_AUTH_TOKEN
  • TWILIO_PHONE_NUMBER (format +34XXXXXXXXX)
Cost aproximat: ~1$/mes per número + ~0,05€/SMS + ~0,05€/conversa WhatsApp.

Alternativa gratis: CSV a LabsMobile

Fins que activis Twilio, usa 📤 Exportar CSV i puja el fitxer a:
  • LabsMobile (~0,03€/SMS · empresa espanyola)
  • SMSarena (~0,03€/SMS)
Ambdós accepten CSV amb 2 columnes: telèfon + missatge.

8. Protecció del codi (anti-clonació)

Què tens protegit

  • ✅ JavaScript obfuscator alt: el codi queda il·legible amb string arrays, control flow flattening i dead code injection
  • ✅ Empaquetat ASAR dins l'.exe (un usuari normal no hi arriba)
  • ✅ DevTools desactivats (F12, Ctrl+Shift+I, Ctrl+U, botó dret tot bloquejat)
  • ✅ Llicència JWT amb secret al servidor: encara que algú copiï l'HTML, no pot generar claus vàlides sense el teu LICENSE_SECRET
  • ✅ Master Key personal no evident (MB-MASTER-BRUGULAT-2026-OWNER)

Què NO es pot protegir (cap empresa pot)

  • ❌ La idea/concepte: 10 min mirant l'app → algú pot fer una còpia amb IA
  • ❌ El disseny visual (CSS és copiable per screenshots)
  • ❌ Reverse engineering profund (40h de feina d'un dev sènior)

Barreres reals (les que et defensen de veritat)

  1. Coneixement del sector DGT — no clonable
  2. Client base + confiança — canviar de proveïdor és molt car per un centre
  3. Suport tècnic en català — barrera d'idioma
  4. Preu baix (30€/mes) — no val la pena copiar per aquest marge

Millores opcionals (per si vols apretar més)

  • ✅ HWID lock — JA IMPLEMENTAT! Cada llicència queda vinculada al maquinari del PC on s'activa per 1a vegada. Si un client vol regalar-la al veí, el sistema la rebutja. Detall complet a sota ⬇️
  • Code signing certificate (~200€/any) — treu l'avís "publicador desconegut" i identifica còpies falses. Recomanat si vendràs a >20 clients
  • Domain-lock de webhook — rebutjar peticions de verificació sospitoses

🔒 HWID Lock — Com funciona

Novetat 07/2026: Sistema anti-pirateig entre clients activat de sèrie.
Com actua:
  1. El client instal·la l'app i activa el JWT al seu PC (PC A)
  2. El backend rep HWID (fingerprint del maquinari) de la petició de verify i el guarda vinculat a la llicència (això és el "binding")
  3. Cada vegada que l'app arrenca, envia el seu HWID actual
  4. Si el HWID coincideix amb el guardat → OK, funciona
  5. Si el HWID és diferent (per exemple algú ha copiat el JWT a un altre PC) → l'app mostra:
    "Aquesta llicència està vinculada a un altre ordinador. Contacta amb el proveïdor per fer el canvi."
Com es genera el HWID (a l'.exe): 
hostname + platform + arquitectura + memòria total + primera MAC address
                             ↓ SHA-256
                     HW-XXXXXXXX...  (24 chars)
Quan un client canvia legítimament de PC:
  1. El client et contacta explicant que ha canviat d'ordinador
  2. Vés a l'admin panel /admin
  3. Localitza la seva llicència a la llista
  4. Clica el botó 🔓 (taronja) — "Desbloquejar HWID"
  5. Confirmes → el HWID guardat es buida
  6. El client obre l'app al nou PC → nou binding automàtic al nou HWID
💡 Comptador de resets: el sistema guarda hwid_reset_count. Si un client demana 3 canvis en 6 mesos, sospita — potser està distribuint la clau a diversos PCs.
Quan un client tingui 2 ordinadors legítims (per exemple oficina + casa):
Solució recomanada: genera-li 2 llicències separades (una per PC, cada una amb el seu Install ID). Cobra un extra (per exemple +50%) per aquest privilegi. Així es respecta el HWID lock i tens ingressos majors.
Endpoint tècnic: POST /api/licenses/{install_id}/reset-hwid (X-Admin-Token requerit).
💡 Recomanació: No obsessionar-se. Focus a captar clients — cada centre nou és una barrera de sortida que un clonador no pot copiar.

10. Preguntes freqüents

Un client canvia d'ordinador, què faig?

Al nou PC, l'app genera un Install ID diferent. El client te l'ha de passar. Entres al admin, generes un JWT nou lligat al nou ID i li envies. L'antic queda inutilitzat.

Com faig una promoció (mesos gratis)?

Al admin, quan aprovis, indica una durada personalitzada (per exemple 90 dies gratis). El JWT porta el exp incorporat i caduca sol.
Amb Stripe Subscriptions actiu, pots crear codis de promoció al Dashboard (paràmetre allow_promotion_codes: true ja habilitat).

El client vol cancel·lar la subscripció mensual (Stripe)?

Amb Subscriptions actiu: el client cancel·la des del Customer Portal de Stripe (endpoint futur). Al final del cicle, el webhook customer.subscription.deleted revoca el JWT sol.
Amb transferència: simplement no li renoves quan caduqui.

Cost mensual del sistema en producció?

  • Domini propi: ~10€/any
  • Hosting (Emergent Deploy o similar): ~15€/mes
  • Stripe: 0€ fix, només comissió (~1,4%)
  • Twilio: ~1$/mes + ~0,05€/SMS
  • Resend: gratis fins a 3000 emails/mes
Total fix: ~15€/mes. Amb 1 client STD anual (299,90€) ja et cobreix l'any sencer.

Puc revendre a 100+ centres alhora?

Sí, escalable de sèrie. Cada centre té JWT únic. El backend gestiona verificacions concurrents amb límit 60 verify/minute per IP.

Què passa si perdo el LICENSE_SECRET?

Totes les llicències existents deixen de verificar-se. Cal regenerar el secret + regenerar tots els JWTs actius + reenviar-los. Fes-ne backup a un gestor de contrasenyes.
