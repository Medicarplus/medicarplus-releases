3. Flux complet de venda · pas a pas

PAS 1 · El client entra al teu formulari
Envies el link /request-license per email, xarxes o al peu de mail.

El client hi troba:
  • Les 3 targetes de preu (TRIAL gratis, STD 30€/mes o 299€/any, PREMIUM 45€/mes o 499€/any)
  • Toggle MENSUAL / ANUAL per triar la periodicitat
  • Formulari amb dades del centre (Empresa, Contacte, Email, NIF, Telèfon)
  • Install ID opcional (si encara no té l'app, el deixa buit; si ja la té, l'enganxa)
  • Consent GDPR
PAS 2 · La sol·licitud arriba al teu admin
Vas a /admin i introdueixes la teva clau (només el primer cop).

Veuràs:
  • Comptador "Sol·licituds" amb badge blau si en tens de pendents
  • Llista amb: empresa, email, telèfon, pla demanat, data
  • Botons per aprovar / rebutjar / veure detalls
PAS 3 · Contactes el client i acordes el pagament
Li envies un email amb:
  1. Confirmació de rebuda
  2. Import a pagar segons el pla que ha triat
  3. 2 opcions de pagament (mira secció Pagaments a sota):
    • 💳 Enllaç Stripe (targeta Visa/MasterCard)
    • 🏦 IBAN per transferència
PAS 4 · El client paga
Opció A — Amb targeta (Stripe):
El client clica l'enllaç i Stripe li obre un formulari segur. Al pagar, tu reps notificació automàtica al admin panel (marcat com "pagat").

Opció B — Transferència:
Fa la transferència al teu IBAN indicant el concepte que li has dit. Quan la veus al teu banc, entres al admin i marques la sol·licitud com "pagada" manualment.
PAS 5 · Generes i envies la llicència
Al admin panel, sobre la sol·licitud aprovada, cliques "✅ Aprovar i generar llicència".

Es genera automàticament un JWT únic vinculat al centre. Li envies per email:
  1. La clau JWT (eyJhbGci...)
  2. El link de descàrrega o l'exe adjunt
  3. Instruccions bàsiques
PAS 6 · El client instal·la i activa
  1. Instal·la l'exe que li has enviat
  2. Al primer arrencament veu la pantalla d'activació
  3. Enganxa el JWT
  4. L'app verifica online amb el teu servidor
  5. Un cop activat, apareix el wizard: nom de les seves 2 empreses + socis opcionals
  6. Ja pot treballar
PAS 7 · Verificació automàtica cada 15 dies
L'app fa un check online al teu servidor. Si tu la revoques (client no paga la propera renovació, per exemple), la propera vegada que faci ping es bloqueja i li apareix la pantalla d'activació de nou.
Si el client no té internet, l'app funciona fins a 30 dies offline. Passat aquest temps, obliga verificació.

Com funciona la transferència bancària

Actualment cal configurar el teu IBAN a l'admin panel. Quan m'ho passis, ho tindràs així:
  1. Al formulari públic, sota les targetes de preu, apareixerà l'opció "🏦 Vull pagar per transferència"

  4. Tu la reps al teu banc, entres al admin, i cliques "✅ Marcar com pagat"
  5. Automàticament genera el JWT i l'envia al client
💡 Recomanació: ofereix les dues opcions. Els clients moderns (menors de 45 anys) prefereixen targeta; els clients tradicionals (autoescoles antigues) prefereixen transferència amb factura formal.

6. Mòdul SMS / WhatsApp · com funciona

Què fa aquest mòdul?

Permet al client (o a tu mateix) enviar recordatoris massius per SMS o WhatsApp a clients seus (ex: "el seu carnet de conduir caduca el X, truqui'ns"). Estalvia el cost de cartes físiques.

Com s'usa (dins l'app):

  1. El client clica el botó 📱 Avisos del header (verd, al costat d'IRPF)
  2. S'obre una finestra amb 5 seccions:
    1. Importar Llista — puja un CSV/Excel amb (Nom, Telèfon, DNI, Data caducitat, Adreça). L'app detecta les columnes automàticament
    2. Afegir manualment — per proves o clients solts, escriu Nom + Telèfon directament
    3. Missatge — plantilla amb variables clicables: {NOM}, {DNI}, {DATA_CADUCITAT}, {ADRECA}
    4. Canals — checkboxes per SMS, WhatsApp, o els dos
    5. Contactes — llista amb checkbox per seleccionar/deseleccionar. Previsualització del missatge personalitzat
  3. Té 2 botons d'acció a baix:
    • 📤 Exportar CSV — descarrega el llistat amb telèfon + missatge personalitzat (per pujar-lo a un servei extern)
    • 🚀 Enviar avisos — envia automàticament via Twilio (SMS + WhatsApp segons canals marcats)

Vinculació amb servei extern (Twilio)

Estat actual: el backend està preparat però Twilio no està configurat. Fins que configuris credencials, el botó "🚀 Enviar avisos" retorna un missatge d'error clar i suggereix usar "📤 Exportar CSV" mentrestant.
Twilio és l'empresa líder mundial d'API d'SMS + WhatsApp. Cost aproximat:
  • SMS a Espanya: ~0.05€ per missatge
  • WhatsApp: ~0.05€ per conversa iniciada (24h de missatges il·limitats amb el mateix client)
  • Número Twilio espanyol: ~1$/mes de manteniment
Per activar l'enviament automàtic des de l'app:
  1. Crea compte a twilio.com/try-twilio (regala 15$ de crèdit inicial)
  2. Al console Twilio, copia:
    • Account SID (AC...)
    • Auth Token (has de clicar "Show")
    • Compra un número espanyol (Phone Numbers → Buy a number) - format +34XXXXXXXXX
    • Per WhatsApp: activa el sandbox (Messaging → Try it out)
  3. Passa-me aquestes 4 dades i les configuro al servidor
  4. Immediatament el botó "🚀 Enviar avisos" comença a funcionar

Alternativa: serveis d'SMS massius amb CSV

Si no vols configurar Twilio, el botó "📤 Exportar CSV" descarrega un fitxer amb 2 columnes: telefon + missatge_ja_personalitzat. Aquest CSV el pots pujar a:
  • LabsMobile (empresa espanyola, ~0.03€/SMS)
  • SMSarena (~0.03€/SMS)
  • Movitel (~0.04€/SMS)
  • Massive SMS, Sinch, etc.
Cadascun d'aquests té una web on puges el CSV, prems "Enviar" i llest. No cal integració tècnica.
💡 Recomanació: comença amb el flux d'Exportar CSV + LabsMobile per validar que el sistema et va bé (100 SMS costaria ~3€). Un cop tinguis clar que t'agrada, migra a Twilio integrat perquè sigui automàtic.

8. Preguntes freqüents

Un client em canvia d'ordinador, què faig?

Al nou PC, l'app genera un Install ID diferent. El client t'ha de passar el nou ID; entres al admin, generes un JWT nou lligat a aquest nou ID i li envies. El JWT antic queda inutilitzat.

Puc fer promocions o descomptes?

Sí. Al admin, quan generes una llicència manualment, pots posar-hi qualsevol data d'expiració. Per exemple, generes un JWT amb exp a 3 mesos vista i li dius "els primers 3 mesos gratis, després paguem".

I si el client vol cancel·lar la subscripció mensual?

Si paga per Stripe (mensual), pots cancel·lar-li la subscripció des del Stripe Dashboard. Al següent cicle no li cobrarà i tu revoques el JWT.
Si paga per transferència (anual), simplement no li renoves el JWT quan caduqui.

Cost mensual de mantenir el sistema en marxa?

Ara mateix el servidor Emergent està en preview (gratis). Quan facis el deploy real, cal:
  • Domini propi (~10€/any)
  • Hosting servidor (Emergent Deploy o similar, ~15€/mes)
  • Stripe: sense cost fix, només comissió per transacció
  • Twilio: sense cost fix, ~1$/mes número + ~0.05€/SMS
Total fix mensual: ~15€. Amb 1 sol client STD anual (299€) ja et surt rendible tot l'any.

Puc revendre a més d'un centre alhora?

Absolutament. Cada centre té la seva llicència JWT única. Pots tenir 1, 100 o 1000 clients — tot el sistema està preparat per escalar.
