Requereix: compte Twilio + número de telèfon (~1$/mes) + verificació.
Cost SMS: ~0,05€/SMS · WhatsApp ~0,05€/conversa.

Ara mateix, quan actualitzes l'app has d'enviar per WeTransfer a cada client. Amb això configurat: git tag v2.0.1 → tots els clients reben l'update automàticament.
Requereix: compte GitHub (gratis) + Personal Access Token.
Guia dedicada: /guia-github-releases.html

4. Últimes novetats (juliol 2026)

🔒 HWID Lock anti-pirateig NOU

Cada llicència queda "casada" amb el maquinari del PC on s'activa per primera vegada. Si algú copia el JWT a un altre PC, l'app el bloqueja amb missatge en català/castellà.
  • Genera HWID via SHA-256(hostname + platform + arch + memòria + MAC)
  • Binding automàtic a la 1a activació
  • Botó admin 🔓 taronja per desbloquejar quan un client canvia de PC legítimament
  • Comptador de resets per detectar abusos

5. Flux complet de venda pas a pas

PAS 1 · El client entra al teu formulari
Envies el link /request-license per email. Al formulari veu 3 targetes de preu, toggle mensual/anual, dades del centre, Install ID opcional i consentiment GDPR.
PAS 2 · La sol·licitud arriba al teu admin
Al `/admin` veus el comptador "Sol·licituds" amb badge blau. Llista amb empresa, email, telèfon, pla, data. Botons per aprovar/rebutjar + 📧 Enviar per email (genera mailto:).
PAS 3 · Cobres al client
Ara mateix: transferència bancària (l'única activa).
Un cop actives Stripe: pagament amb targeta automàtic recurrent.
PAS 4 · Aprovar i generar llicència
Cliques "✅ Aprovar i generar llicència". Es genera un JWT únic. Envia'l amb la guia d'instal·lació.
PAS 5 · Client instal·la i activa
El client obre l'.exe, enganxa el JWT, l'app verifica online, apareix el wizard per configurar empreses+socis, i ja pot treballar. El HWID queda vinculat al seu PC automàticament.
PAS 6 · Verificació periòdica (auto)
L'app fa ping cada 15 dies. Si tu revoques la llicència o el HWID no coincideix, es bloqueja. Sense internet: fins a 30 dies offline.

11. Protecció del codi

Què tens protegit

  • ✅ JavaScript obfuscator alt (string arrays + control flow flattening)
  • ✅ Empaquetat ASAR dins l'.exe
  • ✅ DevTools desactivats (F12, Ctrl+Shift+I, Ctrl+U, botó dret)
  • ✅ JWT amb secret al servidor (impossible generar claus vàlides sense el teu LICENSE_SECRET)
  • ✅ Master Key personal no evident
  • ✅ HWID Lock — llicència vinculada al PC del client (impedeix pirateig entre centres)

🔒 HWID Lock detallat

Com actua:
  1. Client instal·la l'app i activa el JWT al seu PC (PC A)
  2. Backend rep HWID i el guarda vinculat a la llicència (binding)
  3. Cada verify posterior compara HWID
  4. Si HWID diferent → app mostra "Aquesta llicència està vinculada a un altre ordinador. Contacta amb el proveïdor per fer el canvi."
Quan un client canvia de PC legítimament:
  1. Client et contacta
  2. Vés a /admin, localitza la seva llicència
  3. Clica 🔓 (taronja) — Desbloquejar HWID
  4. Confirmes → el HWID guardat es buida
  5. Client obre l'app al nou PC → nou binding automàtic
Comptador de resets: el sistema guarda hwid_reset_count. Si un client demana 3+ canvis en 6 mesos, sospita.
💡 Client amb 2 PCs (oficina+casa): genera 2 llicències separades amb Install IDs diferents. Cobra un extra (+50%). Respecta el HWID lock i tens ingressos majors.

12. Preguntes freqüents

Un client canvia d'ordinador, què faig?

Vés al admin, localitza la seva llicència, clica 🔓 Desbloquejar HWID. Confirmes i llest — al nou PC quedarà vinculada automàticament.

Com faig una promoció (mesos gratis)?

Al aprovar, indica una durada personalitzada (per exemple 90 dies gratis). El JWT porta el exp i caduca sol.
Amb Stripe Subscriptions: crea codis de promoció al Dashboard.

Cost mensual del sistema en producció?

  • Domini: ~10€/any (~1€/mes)
  • Emergent Deploy: ~15€/mes
  • Google Workspace: ~5€/mes (opcional)
  • Stripe: 0€ fix, només comissió (~1,4%)
  • Twilio: ~1$/mes + ~0,05€/SMS
  • Resend: gratis fins 3000 emails/mes
Total fix: ~20-25€/mes. Amb 1 client STD anual (299,90€) ja tens l'any cobert.

Puc revendre a 100+ centres alhora?

Sí, escalable. Cada centre té JWT únic + HWID únic. Backend gestiona verificacions concurrents amb rate limit 60/minute per IP.

Què passa si perdo el LICENSE_SECRET?

Totes les llicències existents deixen de verificar-se. Cal regenerar el secret + regenerar tots els JWTs + reenviar-los. Fes-ne backup a un gestor de contrasenyes.

Per què hi ha "flashos" en obrir el preview?

El servidor preview d'Emergent s'adorm després d'uns minuts sense visites. Quan hi tornes triga 30-60s a despertar-se. Un cop facis el deploy a producció (15€/mes) el servidor NO s'adorm mai i el problema desapareix del tot.

Puc revendre a més d'un centre alhora?

Absolutament. Cada centre té la seva llicència JWT única. Tot el sistema està preparat per escalar.
