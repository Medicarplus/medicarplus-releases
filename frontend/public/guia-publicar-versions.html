📕 Guia per publicar una versió nova de MediCar Plus

Actualitzada · Sistema simplificat · 2 comandes, tot automàtic.

👉 LA COMANDA ÚNICA
cd C:\medicarplus\electron
powershell -ExecutionPolicy Bypass -File .\publish-safe.ps1

Res més. El script fa sol: sync → validate → bump → build → smoke → publish.

🔧 Preparació (només un cop, ja fet)

1Node.js instal·lat · Comprova: node -v ha de retornar ≥18
2GH_TOKEN configurat com a variable d'entorn permanent
Es va fer amb setx GH_TOKEN "ghp_..." · Verifica: 
echo $env:GH_TOKEN
Si un dia expira (dura 1 any), en generes un de nou a github.com/settings/tokens amb permisos repo + workflow i tornes a executar setx GH_TOKEN "...".
3Directori local: C:\medicarplus\electron amb els scripts sync.js, validate-local.js, smoke-test.js, publish-safe.ps1.

1) Fem els canvis (al servidor, jo)
Modifico v2.html, main.js, etc. Els copio automàticament a /downloads/electron-src/.

🛡️ Sistema de seguretat integrat

El publish-safe.ps1 té 5 punts d'aturada automàtica. Si algun falla, no publica res.

Pas 1 falla → sync no pot baixar el codi actualitzat del servidor · ATURA (mai barreges versions vella/nova).
Pas 2 falla → algun fitxer local no té les marques esperades (ex: falta el botó SMS, un ID clau, etc.) · ATURA.
Pas 3 falla → electron-builder no ha pogut compilar · ATURA (dist/ es queda net).
Pas 4 falla → el .exe compilat no conté les marques esperades o és massa petit · ATURA (no arriba a GitHub).
Pas 5 falla → error a l'upload de GitHub (per exemple, token expirat) · ATURA amb missatge clar.

🆘 Emergència — Kill Switch remot

Si algun dia arribés a publicar-se una versió dolenta (impossible amb el sistema, però per si de cas), es pot bloquejar globalment per a tots els clients editant al servidor el fitxer:

/app/backend/electron_channel.json

Contingut:

{
  "latest_safe_version": "2.0.26",
  "blocked_versions": ["2.0.27"],
  "message": "Actualitza a la darrera versio estable"
}

Els clients consulten aquest endpoint abans d'instal·lar cap update. Si la versió està a blocked_versions, no la descarreguen.

🔍 Resolució de problemes comuns

"GH_TOKEN no esta configurat"
Executa: setx GH_TOKEN "ghp_..." · Tanca PowerShell · Obre'n un de nou · Torna a executar publish-safe.ps1.
"sync.js FAIL (HTTP 404)"
Cloudflare pot fer una intermitència momentània. Espera 30s i torna a executar. El sistema té reintents automàtics.
"validate-local.js FAIL: falta marcador X"
Significa que el sync no ha portat tot el codi correctament. Executa node sync.js manualment per veure què falla, i torna a intentar-ho.
