⚠️ Què fer si el GH_TOKEN caduca IMPORTANT

El PAT actual expira segons la política de GitHub. Si un dia executes npm run release i obtens 401 Unauthorized o similar, el token ha caducat.

Regenerar el token (5 minuts)

1Obre github.com/settings/personal-access-tokens (autenticat com Medicarplus)
2Si el token vell hi és → Regenerate. Si no → Generate new token → Fine-grained token
3Nom: medicarplus-release · Expiration: 1 any (o "No expiration")
Repository access: Only select repositories → Medicarplus/medicarplus-releases
Repository permissions:
  • Contents: Read and write
  • Metadata: Read-only (obligatori)
  • Actions: Read and write
4Copia el nou token (comença per github_pat_11...) — només és visible UN COP
5Substitueix-lo al PowerShell: 
$env:GH_TOKEN="EL_NOU_TOKEN_AQUI"
6Actualitza aquesta guia amb el nou token perquè no el perdis. Digues al teu agent:
"Actualitza el GH_TOKEN a la guia amb el nou valor: github_pat_..."

🔧 Configuració NSIS Installer (oneClick)

Instal·lació silenciosa activada. Quan un client fa doble clic al .exe:
  1. NSIS auto-desinstal·la la versió antiga (silenciosament)
  2. Instal·la la nova al mateix lloc
  3. Crea drecera al desktop + menú Inici
  4. Obre l'app automàticament
Total: 3-5 segons, sense preguntes, sense mesclar versions.

Configuració al package.json

"nsis": {
  "oneClick": true,              // silenciós, auto-uninstall previ
  "perMachine": false,           // instal·la per usuari (no requereix admin)
  "allowToChangeInstallationDirectory": false,
  "createDesktopShortcut": true,
  "createStartMenuShortcut": true,
  "runAfterFinish": true,        // obre l'app quan acaba
  "deleteAppDataOnUninstall": false,  // preserva localStorage
  "differentialPackage": true    // updates incrementals (més ràpid)
}

🚨 Recuperació de desastres

En condicions normals, tot ha de funcionar automàticament (auto-sync, oneClick installer, auto-update). Aquestes comandes són només per emergències quan alguna cosa falla i cal reiniciar des de zero.

🆘 Reset TOTAL del client (comanda única d'emergència)

Si l'app d'un client s'ha quedat penjada, mostra versions barrejades, o no arrenca: 
# Tanca l'app, elimina TOT rastre, obliga descàrrega fresca
Get-Process | Where-Object { $_.ProcessName -like "*MediCar*" } | Stop-Process -Force
Start-Sleep -Seconds 2
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\Programs\MediCar Plus" -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force "$env:APPDATA\MediCar Plus" -ErrorAction SilentlyContinue
Remove-Item -Force "$env:USERPROFILE\Desktop\MediCar Plus.lnk" -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\MediCar Plus" -ErrorAction SilentlyContinue
Write-Host "OK - Neteja completa. Descarrega el .exe des de:"
Write-Host "https://github.com/Medicarplus/medicarplus-releases/releases/latest" -ForegroundColor Cyan
⚠️ Preserva les dades del client (localStorage, dies, IRPF, còpies) — només elimina l'installer.

🔧 Reset del PC de desenvolupament (C:\medicarplus\electron\)

Si npm run release falla amb errors estranys o els fitxers font s'han corromput: 
# 1. Backup opcional de node_modules (per no reinstal·lar)
Move-Item C:\medicarplus\electron\node_modules $env:TEMP\node_modules_backup -ErrorAction SilentlyContinue

# 2. Elimina tot excepte node_modules
Remove-Item -Recurse -Force C:\medicarplus\electron\* -Exclude node_modules -ErrorAction SilentlyContinue

# 3. Baixa i extreu últim zip
Invoke-WebRequest "https://project-helper-47.preview.emergentagent.com/downloads/medicar-plus-electron.zip" -OutFile "$env:TEMP\mp.zip"
Expand-Archive -Force "$env:TEMP\mp.zip" -DestinationPath "C:\medicarplus\"

# 4. Restaura node_modules
Move-Item $env:TEMP\node_modules_backup C:\medicarplus\electron\node_modules -ErrorAction SilentlyContinue

# 5. Torna a executar release
cd C:\medicarplus\electron
$env:GH_TOKEN="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"
npm run release

Si el repo GitHub es cau o s'esborra

  1. Crea nou repo public: Medicarplus/medicarplus-releases
  2. El primer npm run release hi puja tot automàticament
  3. Els clients existents seguiran funcionant (offline license) fins que rebin la propera update

Si un client no pot instal·lar l'update

  1. El repo GitHub ha de ser PÚBLIC (comprovar a Settings → Change visibility)
  2. Verifica que hi ha latest.yml al release (el genera electron-builder sol)
  3. El client pot descarregar el .exe manualment i executar-lo — auto-desinstal·larà l'antic
